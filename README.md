# Flask Dashboard

A simple Flask-based dashboard application for data visualization and web interface experiments.

## 🚀 Features
- Built with [Flask](https://flask.palletsprojects.com/)
- Modular structure for easy extension
- Supports dynamic routes and templates
- Ready for deployment on local or cloud servers
